Easily create worlds and manage it !

**4.0.0**: a modern chest-inventory in-game menu, per-world flags (PvP/mob-spawning/
weather-lock/custom spawn), and support down to Paper 1.20.1 (Spigot/CraftBukkit are still not
supported). One plugin covering the same ground as Multiverse-Core plus its Inventories/
NetherPortals addons. See [`AUDIT.md`](AUDIT.md) and [`PATCHNOTES.md`](PATCHNOTES.md) for the
full list of fixes and changes in this release.
